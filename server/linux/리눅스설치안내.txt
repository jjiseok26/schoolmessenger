학교메신저 서버 — 리눅스용 설치 안내
=====================================

화면이 없는 리눅스 서버(우분투 서버 등)에서 돌아가는 버전입니다.
관리는 다른 PC 의 웹 브라우저로 합니다:  http://서버주소:7777/admin

[권장 환경]
 - Ubuntu 22.04 / 24.04, Debian 12, Rocky Linux 9 등 systemd 를 쓰는 64비트 리눅스
 - CPU 2코어, 메모리 2GB 이상 (교직원 100명 기준), 디스크 여유 10GB 이상 (첨부파일 양에 따라)
 - Node.js 18 이상 (20 또는 22 권장)
 - 교내망 고정 IP, 포트 7777/TCP 허용

[1] Node.js 설치 (이미 있으면 건너뜀 — node -v 로 확인)
   Ubuntu 24.04 / Debian 12 :  sudo apt update && sudo apt install -y nodejs
   Ubuntu 22.04 (기본 nodejs 가 너무 오래됨) :
       curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
       sudo apt install -y nodejs
   Rocky / RHEL 9 :  sudo dnf module install -y nodejs:20   (또는 sudo dnf install -y nodejs)

[2] 설치
   tar -xzf SchoolMessenger-Server-Linux-x.x.x.tar.gz
   cd school-messenger-server
   sudo bash install.sh

   → /opt/school-messenger-server 에 설치되고, school-messenger-server 서비스로 등록되어
     부팅 때 자동으로 실행됩니다. 마지막에 접속 주소와 웹 관리 화면 주소가 표시됩니다.

[3] 처음 설정 (웹 관리 화면)
   1. 다른 PC 의 브라우저에서 http://서버주소:7777/admin 접속
   2. admin / admin1234 로 로그인 → [사용자 관리]에서 admin 의 비밀번호부터 바꾸기
   3. 학교 이름 입력, 교직원 계정 만들기(엑셀 가져오기 가능)
   교직원 PC 에는 윈도우용 클라이언트(SchoolMessenger-Client-Setup-x.x.x.exe)를 설치하고
   서버 주소에 "서버IP:7777" 을 넣으면 됩니다.

[4] 자주 쓰는 명령
   상태 보기      sudo systemctl status school-messenger-server
   다시 시작      sudo systemctl restart school-messenger-server
   멈추기         sudo systemctl stop school-messenger-server
   실행 기록      sudo journalctl -u school-messenger-server -f
   설정 파일      /var/lib/school-messenger-server/settings.json  (포트·학교 이름·데이터 위치)
   데이터 폴더    /var/lib/school-messenger-server/serverdata
   백업 폴더      /var/lib/school-messenger-server/backups  (웹 관리 화면 [백업 내보내기])

[5] 업데이트
   - 자동: 웹 관리 화면 [프로그램 업데이트]에서 GitHub 자동 업데이트를 켜 두면(기본 켜짐)
     6시간마다 새 버전을 확인해서, 접속한 사람이 없을 때 스스로 바꾸고 다시 시작합니다.
     새 윈도우 클라이언트도 받아서 교직원 메신저에 자동으로 배포합니다.
     (서버가 인터넷의 github.com 에 접속할 수 있어야 합니다)
   - 직접: 새 tar.gz 를 받아 [2] 를 다시 하면 됩니다. 데이터는 그대로 남습니다.

[6] 포트를 바꾸려면
   웹 관리 화면 [서버 상태] 에서 포트를 바꾸거나 settings.json 의 "port" 를 고친 뒤 다시 시작하세요.
   방화벽도 새 포트를 열어야 합니다 (예: sudo ufw allow 8080/tcp).

[7] 제거
   sudo bash /opt/school-messenger-server/uninstall.sh            (데이터는 남김)
   sudo bash /opt/school-messenger-server/uninstall.sh --purge    (데이터까지 삭제)
