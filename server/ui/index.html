person_add회원가입 요청 0

교직원 메신저 로그인 화면에서 들어온 가입 요청입니다. 승인하면 바로 로그인할 수 있습니다.

account_tree부서(그룹) 표시 순서

교직원 메신저 조직도의 부서 순서입니다. 끌어 놓거나 ▲▼ 로 바꾸면 접속 중인 모든 메신저에 바로 반영됩니다.
교과-○○ 그룹은 교직원의 담당 과목으로 자동으로 만들어지며, 여기서 순서를 정할 수 있습니다.
