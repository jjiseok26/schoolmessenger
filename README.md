# 🏫 학교메신저 (School Messenger)

쿨메신저처럼 학교(교내망)에서 사용하는 사내 메신저입니다.
외부 인터넷 없이 **학교 내부 네트워크만으로** 동작합니다. (인터넷이 되면 GitHub 자동 업데이트도 사용 가능)

## 구성

| 구분 | 폴더 | 설치파일 | 용도 |
|------|------|----------|------|
| 서버 (Windows) | `server/` | `SchoolMessenger-Server-Setup-1.0.1.exe` | 교내 서버 PC 1대에 설치 (계정 관리 포함) |
| 서버 (Linux) | `server/` | `SchoolMessenger-Server-Linux-1.0.1.tar.gz` | 화면 없는 리눅스 서버에 설치, 관리는 웹 브라우저 (`http://서버주소:7777/admin`) |
| 클라이언트 | `client/` | `SchoolMessenger-Client-Setup-1.0.1.exe` | 교직원 각자 PC에 설치 |

설치파일은 GitHub **[Releases](../../releases)** 에서 받을 수 있습니다. 서버는 둘 중 **하나만** 설치하면 됩니다.

> 📘 **[사용 설명서 (MANUAL.md)](MANUAL.md)** — 서버·클라이언트 설치부터 쪽지·공지·설문·관리자 기능·업데이트·리눅스 서버까지 화면과 함께 순서대로 정리했습니다.

## 권장 설치 기준

교직원 **100~200명** 규모 학교 기준입니다. (데이터는 JSON 파일 하나와 첨부파일 폴더에 저장되며, 별도 DB 설치가 필요 없습니다)

### 서버 — Windows

| 항목 | 최소 | 권장 |
|---|---|---|
| 운영체제 | Windows 10 64비트 | Windows 10/11 64비트 (Windows Server 2016 이상도 가능) |
| CPU | 2코어 | 4코어 이상 |
| 메모리 | 4GB | 8GB 이상 |
| 디스크 여유 공간 | 10GB | 50GB 이상 (첨부파일 양에 따라 — 보관 기간 설정으로 자동 정리 가능) |
| 네트워크 | 교내망 유선 연결 | **고정 IP**, 유선 1Gbps |
| 방화벽 | 포트 **7777/TCP** 들어오는 연결 허용 (처음 실행 때 [허용]) | |
| 운영 | 업무 시간 내내 켜 둠, **절전 모드 끄기** | 24시간 켜 두는 PC |
| 인터넷 (선택) | 없어도 됨 | GitHub 자동 업데이트를 쓰려면 `github.com`, `api.github.com`, `objects.githubusercontent.com` 접속 허용 |

### 서버 — Linux

| 항목 | 최소 | 권장 |
|---|---|---|

| Node.js | 18 이상 | 20 또는 22 LTS |
| CPU / 메모리 | 1코어 / 1GB | 2코어 / 2GB 이상 |
| 디스크 여유 공간 | 10GB | 50GB 이상 |
| 네트워크 | 포트 7777/TCP 허용 | 고정 IP |

### 클라이언트 (교직원 PC)

| 항목 | 최소 | 권장 |
|---|---|---|
| 운영체제 | Windows 10 64비트 | Windows 10/11 64비트 |
| 메모리 | 4GB | 8GB 이상 |
| 디스크 여유 공간 | 500MB (+ 받은 첨부파일) | 2GB 이상 |

| 네트워크 | 서버와 같은 교내망 (유선·무선 모두 가능) | |

## 주요 기능

- **쪽지**: 여러 명에게 동시 발송, 파일 첨부(최대 200MB, 여러 번 누적 추가), 읽음 확인, 내용/이름 검색, **전달**, **회수**(상대가 읽은 뒤에도 가능), **삭제**(내 보관함에서만), **예약 발송**(원하는 시각에 자동 발송, 취소 가능)
- **쪽지·공지 창 여러 개**: 받은쪽지·보낸쪽지·**공지사항**을 누를 때마다 따로 떠 있는 **큰 창**(쪽지 쓰기 창만 한 크기, 최대 1100×720)으로 열려 **여러 개를 동시에** 볼 수 있음. 제목줄 색으로 구분(받은 쪽지 파랑 · 보낸 쪽지 초록 · 공지 주황). 창은 제목줄을 끌어 옮기고, [—]로 접고, 모서리로 크기를 바꿀 수 있으며 Esc로 맨 앞 창을 닫음. 공지 창에서 설문 투표·[지금 마감]·결과 엑셀 저장·인쇄·[수정]·[공지 삭제]까지 가능. 쪽지 쓰기 창보다 위에 떠서 **쪽지를 보면서 답장·새 쪽지를 쓸 수 있고**, 이때 쓰기 창은 왼쪽, 쪽지·공지 창은 오른쪽으로 정렬되어 겹치지 않음
- **나에게 보내기**: 쪽지 보내기 창의 [나에게 보내기] 버튼으로 나에게 쪽지를 보내 메모처럼 사용
- **새 쪽지 강조**: 안 읽은 쪽지는 빨간 [NEW] 라벨·굵은 글씨·색 배경으로 표시, 받은쪽지 탭을 누르면 항상 최신부터
- **검색**: 받은쪽지함은 보낸 사람·내용·첨부 이름, 보낸쪽지함은 받는 사람·내용·첨부 이름으로 검색
- **대화 / 채팅방**: 1:1 실시간 채팅, 그룹 채팅방(초대·나가기·안 읽은 수), **채팅방 설문**(그 방 사람들만 대상)
  - **채팅방 글 수정·회수**: 내 글에 마우스를 올려 [수정]·[회수] — 수정하면 모두의 화면에 '수정됨' 표시, 회수하면 '회수된 메시지입니다'만 남음 (빈 입력칸에서 ↑ 키 = 방금 쓴 글 고치기)
- **공지사항·설문조사**: 누구나 공지 등록, 작성자·관리자가 수정/삭제, 예약 공지. 설문은 **하나만/여러 개 선택**, **투표자 공개/익명**, **결과는 마감 후에만 공개**, [지금 마감], **결과 엑셀 저장**(결과·응답자별·미참여 시트)
- **조직도 / 사용자 그룹**: 부서·학년별 조직도(트리형 부서 예: 교과-국어), 담당 과목으로 **교과 그룹 자동 구성**, 실시간 접속·상태(아이콘 오른쪽 아래 **큰 상태 점**), [전체][접속][미접속] 필터, **내가 만드는 사용자 그룹**(그룹 단위 쪽지·채팅방, 쪽지에서 바로 만들기)
  - **조직도 아이콘 꾸미기**: [내 정보]에서 모양(원·둥근 네모·네모·육각형·꽃)·색(16색)·안의 글자(이름 첫 글자/직접 입력 2자·이모지/그림 28가지)를 골라 다른 선생님 조직도에도 그대로 표시
  - **사용자 그룹 순서 바꾸기**: 그룹을 끌어 놓거나 ▲▼ 버튼 (내 순서는 서버에 저장되어 다른 PC에서도 같음)
  - **부서·교과 그룹 순서**: 관리자가 조직도에서 부서 제목을 끌어 놓거나 서버 관리 화면의 [부서 표시 순서]에서 지정 — 과목으로 자동 생기는 **교과-○○ 그룹도 순서를 정할 수 있음** (정하지 않은 교과는 맨 뒤)
- **Google 스타일 화면 (Material 3)**: 서버·클라이언트 모두 Gmail 처럼 둥근 판·알약 모양 버튼·Material 아이콘(인터넷 없이도 보이게 프로그램에 포함)·세그먼트 탭·검색창, 다크 모드도 같은 색 체계
- **내 정보**: 부서·사무실·과목·전화·핸드폰·이메일·비밀번호 변경, 전화번호는 숫자만 쳐도 **하이픈 자동 입력**(062-123-4567, 010-1234-5678 / 내선 번호는 그대로)
- **로그인**: 서버 주소는 **하나만** 입력·저장 (새 주소로 로그인하면 바뀜), 한 PC에서 여러 계정을 저장해 골라 쓰기
- **조직 관리 / 회원가입 승인**(클라이언트): 관리자 권한 사용자는 메신저에서 계정 관리, 가입 요청 알림·승인/거절
- **계정 관리**(서버): [계정 추가]·[✏ 수정] 창에서 **세부 정보까지 관리** — 아이디·이름·부서(여러 개)·직위·**담당 과목·사무실 위치·사무실 전화·핸드폰·이메일**·관리자 권한·비밀번호. 엑셀/CSV 가져오기·내보내기도 세부 정보 열 지원
- **자동 업데이트 (GitHub)**
  - **서버**: 6시간마다 GitHub 릴리스를 확인 → 새 서버 버전을 받아 두었다가 **접속자가 없을 때 자동 설치·재시작**(또는 [서버 업데이트 설치]), 새 클라이언트 설치파일은 받아서 **바로 배포 등록**
  - **클라이언트**: 로그인할 때 **서버에 등록된 새 버전**을 받거나, 서버에 없으면 **GitHub(공개 저장소)에서 직접** 받음 → 상단 배너 [지금 재시작하여 업데이트] (그냥 종료해도 종료 시 자동 설치). [정보] 창에서 [업데이트 확인]
  - 인터넷이 막힌 학교는 서버 관리 화면에서 클라이언트 설치파일을 **직접 등록**해 배포
- **리눅스 서버 + 웹 관리 화면**: `node` 로 실행하는 화면 없는 서버(systemd 서비스로 부팅 시 자동 실행), 관리는 다른 PC 브라우저로 `http://서버주소:7777/admin` (관리자 계정 로그인, 윈도우 관리 화면과 같은 기능)
- **알림 / 첨부**: 데스크톱 알림·작업표시줄 깜빡임·알림음, 사진·영상·소리 미리보기, 첨부 [열기]·[폴더], 그림 붙여넣기·우클릭 저장, 드래그앤드롭 첨부
- **기타**: 트레이 상주, 다크 모드, 링크 클릭 시 브라우저로 열기, 학교 이름 표시, Windows 시작 시 자동 실행
- **보안**: WebSocket 연결마다 ECDH 키 교환 + AES-256-GCM 으로 모든 메시지 암호화, 업데이트 파일은 크기·SHA-256 검증
- **데이터 관리**(서버): 저장 용량 현황, 보관 기간(자동 정리), 백업 내보내기/복원, 데이터 저장 위치 변경, 활동 로그
- **가벼운 서버 (1.0.1~)**: 쪽지·채팅을 날짜별 파일(`messages/`, `roommsgs/`)로 나눠 **바뀐 날짜만 백그라운드로 저장** — 데이터가 쌓여도 채팅·로그인 때 서버가 멈추지 않음
  (한 학기 분량 시험 기준 저장 1회 멈춤 약 2초 → 0.02초, 채팅 왕복 최대 0.78초 → 0.01초). 첨부파일은 받는 대로 디스크에 써서 메모리를 아끼고,
  관리 창을 닫으면 관리 화면이 쓰던 메모리도 돌려줌. 1.0.0 이하 데이터는 처음 실행 때 자동으로 옮김(`data.json.before-1.0.1` 로 원본 보관)
- **빠른 클라이언트 (1.0.1~)**: 화면 밖 쪽지 목록은 그리지 않아 로그인·탭 전환이 빨라짐 (쪽지 500개 받은쪽지함 0.7초 → 0.08초)

## 설치 및 사용 방법

> 화면과 함께 자세히 보려면 **[사용 설명서](MANUAL.md)**를 참고하세요. 아래는 요약입니다.

### 1. 서버 설치 — Windows (학교에서 1대만)

1. 항상 켜져 있는 PC(교무실 등)에 `SchoolMessenger-Server-Setup-1.0.1.exe` 실행
2. 첫 실행 시 **학교 이름**을 입력합니다 (나중에 변경 가능)
3. Windows 방화벽 허용 창이 뜨면 **허용**
4. 관리 화면 [서버 상태]의 **접속 주소**(예: `10.112.120.40:7777`)를 교직원에게 알려 줍니다
5. [사용자 관리] → **[계정 추가]** 또는 **[엑셀/CSV 가져오기]**로 교직원 계정 등록
   - 엑셀 열 순서: `아이디 | 이름 | 부서 | 직위 | 비밀번호 | 담당과목 | 사무실위치 | 사무실전화 | 핸드폰 | 이메일` (비밀번호 생략 시 1234, 6번째 열부터는 없어도 됨)
6. 기본 관리자 계정: `admin / admin1234` → **반드시 비밀번호를 변경하세요**
7. 관리 창을 닫아도 서버는 트레이에서 계속 실행됩니다 (종료: 트레이 아이콘 우클릭 → 서버 종료)

### 1-2. 서버 설치 — Linux (Windows 서버 대신)

```bash
# Node.js 18 이상 필요 (node -v 로 확인)
tar -xzf SchoolMessenger-Server-Linux-1.0.1.tar.gz
cd school-messenger-server
sudo bash install.sh
```

→ `/opt/school-messenger-server` 에 설치되고 `school-messenger-server` 서비스로 부팅 때 자동 실행됩니다.
다른 PC 브라우저에서 `http://서버주소:7777/admin` 에 `admin / admin1234` 로 로그인해 관리합니다. 자세한 내용은 꾸러미 안의 `리눅스설치안내.txt` 와 [사용 설명서](MANUAL.md#15-리눅스-서버).

### 2. 클라이언트 설치 (교직원 PC마다)

1. `SchoolMessenger-Client-Setup-1.0.1.exe` 실행
2. 로그인 화면에 서버 관리 화면에 표시된 **서버 주소** 하나 입력 (예: `10.112.120.40:7777`)
3. 서버에서 등록받은 아이디/비밀번호로 로그인 (계정이 없으면 [회원가입 요청] → 관리자 승인)

### 3. 업데이트

- **GitHub 자동 업데이트** (서버 관리 화면 [프로그램 업데이트], 기본 켜짐): 서버가 새 버전을 확인해 서버는 접속자가 없을 때 스스로 설치하고, 새 클라이언트는 교직원 PC에 자동 배포합니다.
  - 저장소가 **공개**면 그대로 동작합니다.
  - 저장소가 **비공개**면 GitHub 에서 읽기 전용 토큰을 만들어 [GitHub 토큰] 칸에 넣으세요
    (GitHub → Settings → Developer settings → Fine-grained tokens → 이 저장소만 선택, 권한 **Contents: Read-only**).
- **인터넷이 막힌 경우**: 서버는 새 설치파일을 덮어 설치(데이터 유지), 클라이언트는 [프로그램 업데이트] → [클라이언트 설치파일 직접 등록].

## 개발자용

```bash
# 서버 실행(개발)
cd server && npm install && npm start

# 리눅스 방식(화면 없이)으로 서버 실행 — 웹 관리 화면 http://localhost:7777/admin
cd server && node headless.js --home ./tmp-home

# 클라이언트 실행(개발)
cd client && npm install && npm start

# 설치파일 빌드 (각 폴더의 dist/ 에 생성)
npm run dist              # 윈도우 설치파일 (client/, server/)
npm run dist:linux        # 리눅스 서버 꾸러미 (server/ 에서) → SchoolMessenger-Server-Linux-<버전>.tar.gz
```

- **릴리스 올리기**: 태그 `v<버전>` 으로 GitHub Release 를 만들고 위 3개 파일을 그대로(이름 바꾸지 않고) 첨부하면 자동 업데이트가 인식합니다.
  (`SchoolMessenger-Client-Setup-x.y.z.exe`, `SchoolMessenger-Server-Setup-x.y.z.exe`, `SchoolMessenger-Server-Linux-x.y.z.tar.gz`)
- 서버 데이터 저장 위치: Windows `%APPDATA%\school-messenger-server\serverdata\`, Linux `/var/lib/school-messenger-server/serverdata/`
  (`data.json` = 계정/쪽지/채팅방/공지, `uploads/` = 첨부파일)
- 서버 포트 기본값: **7777** (관리 화면에서 변경 가능)

## 기술 스택

- Electron (윈도우 서버 관리 UI + 클라이언트), Node.js (리눅스 서버)
- Express + WebSocket(ws), 데이터: JSON 파일 저장 (별도 DB 설치 불필요)
- 화면: Material 3 (Google) 디자인, Material Symbols 아이콘 (Apache-2.0, 프로그램에 포함)
