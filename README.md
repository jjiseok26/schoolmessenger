# 🏫 학교메신저 (School Messenger)

쿨메신저처럼 학교(교내망)에서 사용하는 사내 메신저입니다.
외부 인터넷 없이 **학교 내부 네트워크만으로** 동작합니다.

## 구성

| 구분 | 폴더 | 설치파일 | 용도 |
|------|------|----------|------|
| 서버 | `server/` | `SchoolMessenger-Server-Setup-0.9.8.exe` | 교내 서버 PC 1대에 설치 (계정 관리 포함) |
| 클라이언트 | `client/` | `SchoolMessenger-Client-Setup-0.9.8.exe` | 교직원 각자 PC에 설치 |

## 주요 기능

- **쪽지**: 여러 명에게 동시 발송, 파일 첨부(최대 200MB, 여러 번 누적 추가), 읽음 확인, 내용/이름 검색, **전달**, **회수**(상대가 읽은 뒤에도 가능), **삭제**(내 보관함에서만), **예약 발송**(원하는 시각에 자동 발송, 취소 가능)
- **나에게 보내기**: 쪽지 보내기 창의 [👤 나에게 보내기] 버튼으로 나에게 쪽지를 보내 메모처럼 사용. 받은쪽지함에 [메모] 라벨로 표시되고 안 읽음 개수에는 포함되지 않음
- **새 쪽지 강조**: 안 읽은 쪽지는 빨간 [NEW] 라벨과 색 배경으로 표시되고, 받은쪽지 탭을 누르면 목록이 항상 맨 위(최신)부터 보임. 검색 중에는 "전체 N건 중 M건 표시"로 가려진 쪽지를 알려 줌
- **검색**: 받은쪽지함은 보낸 사람·내용·첨부 이름으로, 보낸쪽지함은 받는 사람·내용·첨부 이름으로 검색(같이 받은 사람 이름으로 엉뚱한 쪽지가 걸리지 않음). 조직도·쪽지함 검색창의 ✕ 버튼으로 검색어를 한 번에 지움
- **대화**: 1:1 실시간 채팅 (조직도에서 이름 두 번 클릭 또는 우클릭 메뉴)
- **채팅방**: 그룹 채팅방 만들기·초대·나가기, 안 읽은 메시지 수 표시, **채팅방 설문**(그 방 사람들만 대상으로 하는 소규모 설문), **쪽지에서 채팅방 만들기**(여러 명이 주고받은 쪽지의 [👥 N명과 채팅방 만들기] → 그 사람들과 이름이 미리 채워진 채로 만들고 바로 입장, 같은 사람들로 된 방이 이미 있으면 그 방으로 안내)
- **공지사항**: 누구나 공지 등록, 작성자·관리자가 수정/삭제, **설문조사**(기간 설정·자동 마감·마감 후 결과 공개), **예약 공지**
- **설문조사**: 공지사항(전체 대상)과 채팅방(일부 인원 대상) 양쪽에서 가능. 만들 때 **하나만 선택 / 여러 개 선택**과 **투표자 공개 / 미공개(익명)**를 정할 수 있음. **투표 결과는 설문이 끝난 뒤에만 공개**되고 진행 중에는 참여 인원과 내 선택만 보임 (서버가 마감 전에는 결과를 아예 보내지 않음). 만든 사람·관리자는 [⏹ 지금 마감]으로 바로 끝내고 결과를 공개할 수 있음. 공개 설문은 마감 후 항목마다 투표한 사람 이름이 표시됨 (익명 설문은 서버가 투표자 정보를 아예 보내지 않음)
- **조직도/사용자 그룹**: 부서/학년별 조직도 + **내가 만드는 사용자 그룹**(그룹 단위 쪽지·채팅방), 실시간 접속·상태 표시, **[전체] [접속] [미접속] 필터**(인원 수 표시, 접속 상태가 바뀌면 바로 반영), 트리형 부서(예: 교과-국어), 관리자 드래그앤드롭 순서 변경·부서 이름 변경(병합)
- **조직 관리**(클라이언트): 관리자 권한 사용자는 메신저에서 바로 계정 추가·수정·삭제 가능
- **회원가입 승인**(클라이언트): 새 가입 요청이 오면 관리자에게 알림이 뜨고, 상단 [가입요청] 버튼(대기 건수 배지)에서 바로 승인/거절 가능 (서버 프로그램에서 처리해도 즉시 반영)
- **알림**: 새 쪽지/채팅/공지 도착 시 데스크톱 알림 + 작업표시줄 깜빡임 + 알림음(설정에서 켜고 끔)
- **미디어 미리보기**: 사진은 물론 영상·오디오 첨부도 쪽지·대화에서 바로 재생
- **첨부파일 바로 열기**: 쪽지 창을 열어 둔 채로 첨부파일 줄의 [📂 열기] [📁 폴더] 버튼으로 파일을 바로 실행하거나 저장된 폴더를 열 수 있음 (아직 안 받았으면 받은 뒤 실행, 이미 받은 파일은 다시 받지 않음)
- **그림 붙여넣기**: 쪽지 본문은 물론 대화·채팅방 입력창에도 그림을 복사해 붙여넣으면 바로 첨부됨 (본문에 넣은 그림은 첨부 목록에서 미리보기를 중복 표시하지 않음)
- **그림 우클릭**: 대화·쪽지 속 그림을 오른쪽 버튼으로 눌러 저장하거나 복사. 입력창에서는 복사/잘라내기/붙여넣기/모두 선택 메뉴 제공
- **첨부 저장 폴더**: 기본값 `문서\schoolmessenger`, 클라이언트 설정에서 변경 가능
- **트레이 상주**: 창을 닫아도 트레이에서 계속 실행 (서버는 관리 창을 닫아도 서비스 유지)
- **다크 모드**: 클라이언트 설정에서 켜고 끔
- **링크 활성화**: 쪽지·대화·공지 속 URL을 클릭하면 기본 브라우저로 열림
- **학교 이름**: 서버에서 학교 이름을 설정하면 서버 제목표시줄과 모든 클라이언트 화면에 표시
- **드래그앤드롭 첨부**: 파일을 쪽지 작성 창·대화·채팅방에 끌어다 놓으면 첨부됨 (대화·채팅방은 입력창 위에 첨부 목록으로 쌓아 두었다가 [전송]으로 함께 발송, ✕로 개별 취소)
- **클라이언트 자동 업데이트**: 서버에 새 클라이언트 설치파일을 등록하면 구버전 클라이언트가 로그인할 때 백그라운드로 내려받고, 상단 배너의 [지금 재시작하여 업데이트] 버튼 한 번으로 무음 설치 후 새 버전이 자동 실행됨 (배너를 닫고 그냥 종료해도 종료 시 자동 설치)
- **자동 실행**: Windows 시작 시 자동 실행 옵션 (서버·클라이언트 모두)
- **계정 관리**(서버 앱): 개별 추가, 일괄 등록, **엑셀(xlsx)/CSV 가져오기·내보내기**, 계정 수정·비밀번호 변경, 관리자 지정
- **메시지 암호화**: WebSocket 연결마다 ECDH 키 교환 + AES-256-GCM으로 모든 메시지(쪽지·대화·공지)를 전송 암호화
- **보관함 용량 관리**(서버 앱): 저장 용량 현황, 보관 기간 설정(기간 경과 쪽지·채팅·첨부파일 자동 삭제), 수동 정리

## 설치 및 사용 방법

### 1. 서버 설치 (학교에서 1대만)

1. 항상 켜져 있는 PC(교무실 등)에 `SchoolMessenger-Server-Setup-0.9.8.exe` 실행
2. 첫 실행 시 **학교 이름**을 입력합니다 (나중에 변경 가능)
3. 관리 화면에 **접속 주소**(예: `192.168.0.10:7777`)가 표시됩니다
4. **사용자 관리**에서 교직원 계정을 등록합니다
   - 일괄 등록/엑셀 형식: `아이디 | 이름 | 부서 | 직위 | 비밀번호` 열 순서 (비밀번호 생략 시 1234)
4. Windows 방화벽 허용 창이 뜨면 **허용**을 눌러주세요
5. 기본 관리자 계정: `admin / admin1234` → **반드시 비밀번호를 변경하세요**
6. 관리 창을 닫아도 서버는 트레이에서 계속 실행됩니다 (종료: 트레이 아이콘 우클릭 → 서버 종료)

### 2. 클라이언트 설치 (교직원 PC마다)

1. `SchoolMessenger-Client-Setup-0.9.8.exe` 실행
2. 로그인 화면에서 서버 관리 화면에 표시된 **서버 주소**를 입력
3. 서버에서 등록받은 아이디/비밀번호로 로그인

## 개발자용

```bash
# 서버 실행(개발)
cd server && npm install && npm start

# 클라이언트 실행(개발)
cd client && npm install && npm start

# 설치파일 빌드 (각 폴더의 dist/ 에 생성)
npm run dist
```

- 서버 데이터 저장 위치: `%APPDATA%\school-messenger-server\serverdata\`
  (`data.json` = 계정/쪽지/채팅방/공지, `uploads/` = 첨부파일)
- 서버 포트 기본값: **7777** (관리 화면에서 변경 가능)

## 기술 스택

- Electron (서버 관리 UI + 클라이언트)
- Node.js + Express + WebSocket(ws)
- 데이터: JSON 파일 저장 (별도 DB 설치 불필요)
